# Jarvis

Asistente personal por voz, de costo cero. Vive en la nube gratis (Render + Turso) y usa el PC como extra cuando está encendido.

- Orbe azul estilo Iron Man, saludo "Hola, señor."
- Enrutador de modelos con cuotas: Gemini, Groq, Mistral, OpenRouter, Cloudflare, Ollama; puestos para Claude, ChatGPT, Grok y Perplexity.
- Cola de tareas para el PC (modo Preparar y modo Directo a Claude, texto exacto).
- iPhone: web instalable con Safari, Telegram y Atajos.

Plan completo en `docs/PLAN.md`. Las claves van en `.env` (nunca en git).
